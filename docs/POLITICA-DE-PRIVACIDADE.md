# Política de Privacidade — SEI Protocolistas

**Última atualização:** 10 de agosto de 2026

O **SEI Protocolistas** é uma extensão gratuita e de código aberto criada para auxiliar protocolistas em tarefas realizadas no Sistema Eletrônico de Informações (SEI-RJ) e no webmail institucional.

Esta extensão é uma iniciativa independente e não é um produto oficial do DETRAN-RJ, do Governo do Estado do Rio de Janeiro ou dos responsáveis pelo SEI.

## Dados processados

Para executar as funções solicitadas pelo usuário, a extensão pode processar localmente informações exibidas nas páginas autorizadas do SEI-RJ e do webmail institucional, incluindo:

- dados de identificação presentes em e-mails, formulários e processos;
- conteúdo de mensagens e documentos abertos pelo usuário;
- dados necessários à continuidade do fluxo entre o webmail e o SEI-RJ;
- informações de autenticação preenchidas ou utilizadas pelo próprio usuário; e
- configurações e preferências da extensão.

## Como os dados são utilizados

Os dados são utilizados exclusivamente para executar os recursos da extensão, como organizar informações, preencher campos, preparar processos e respostas padronizadas e manter preferências do usuário.

O processamento ocorre localmente no navegador e nos ambientes institucionais acessados pelo usuário. A extensão não possui servidor próprio para coletar, armazenar ou transmitir dados de cidadãos, documentos, mensagens ou credenciais.

## Armazenamento local

A permissão `storage` é utilizada para guardar localmente configurações, preferências e dados temporários necessários ao funcionamento dos fluxos. Essas informações permanecem no navegador do usuário e podem ser removidas ao limpar os dados da extensão ou desinstalá-la.

## Compartilhamento e comercialização

O SEI Protocolistas:

- não vende dados de usuários;
- não transfere dados a terceiros;
- não utiliza dados para publicidade, perfilamento, crédito ou empréstimos; e
- não utiliza dados para finalidades diferentes das funcionalidades declaradas da extensão.

## Permissões de acesso

A extensão solicita acesso apenas aos endereços necessários ao seu funcionamento no SEI-RJ e no webmail institucional. Essas permissões permitem executar as automações e os preenchimentos solicitados pelo usuário diretamente nas páginas correspondentes.

## Código remoto

A extensão não baixa nem executa código JavaScript remoto. Todo o código executável está incluído no pacote distribuído pela Chrome Web Store.

## Segurança e responsabilidade do usuário

A extensão foi projetada para reduzir tarefas repetitivas, mas o usuário continua responsável por conferir as informações e ações antes de concluir procedimentos institucionais. Credenciais e dados sensíveis não devem ser compartilhados fora dos ambientes oficiais.

## Alterações nesta política

Esta política poderá ser atualizada quando houver mudança relevante nas funcionalidades ou no tratamento de dados. A data da revisão mais recente será informada no início deste documento.
